# fedtuna-di weights

Model weights for [fedtuna-ai/di](https://github.com/fedtuna-ai/di), the
liveness (face anti-spoofing) data-intelligence pilot.

The weight files are published as versioned release archives (`weights-v2`, ...),
each with its `MANIFEST.json` and `SHA256SUMS`. See the releases for downloads.
The library never downloads weights on its own; use `scripts/fetch_weights.py`
from the code repository.
